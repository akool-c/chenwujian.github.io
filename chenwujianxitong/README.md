# 鹿寨中学 因病缺勤病例追踪填报系统

基于《因病缺勤师生病例追踪表模板》开发的 Web 填报 + 数据管理导出系统。

## 功能
- 学生表 / 教师表 双表填报（完全对齐模板字段）
- 支持不同日期填报（按发病日期/填报日期区分）
- 症状勾选、处理情况、多次随访动态添加
- 数据本地存储（localStorage），刷新不丢失
- 一键导出 Excel（.xlsx）和 CSV
- 列表查看、编辑、删除、统计

## 使用
直接用浏览器打开 index.html 即可（无需联网、无需服务器）。
建议用 Chrome / Edge。

## 字段说明（同附件）
- 腹泻：每日大便超过3次
- 病例转归：加重 / 无变化 / 好转 / 痊愈
- 随访次数可如实增加
